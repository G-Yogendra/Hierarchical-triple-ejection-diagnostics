# v1.1.0 release notes — application-transfer layer

## Relationship to v1.0.3

v1.0.3 remains the unchanged frozen source-layer release. v1.1.0 adds the audited application-transfer layer and does not rewrite source results.

## Added

- deterministic compact, field-like, and young-cluster-like target generators;
- exact four-config release contracts;
- target simulation/checkpoint runner;
- deterministic source-model reconstruction workflow;
- zero-shot/source-threshold, target-calibrated, and target-refit analysis;
- MA01, V22 formula, V22 MLP, and V23 ghost-MLP comparators;
- warning coverage/control-alert/lead operation;
- absolute and paired bootstrap addendum;
- seven failure/competing-risk scenarios;
- official 150/60/105/15-row machine-readable tables;
- application script and artifact registries;
- CI and application-contract tests;
- exact archival copies of the two self-contained 10,000-system launcher scripts, byte-unmodified and hash-pinned, with their embedded 816,912-byte simulation package verified from both scripts.

## Not included

Large NPZ/JSONL arrays and serialized model objects remain in external versioned datasets. A DOI-backed consolidated archive is a manuscript-submission task, not a prerequisite for this source release.

## Claim boundary

The target populations are engineering proxies. v1.1.0 makes no realistic-population, PN/GW, merger-rate, individual-system, or full-cluster claim.

All simulation campaigns ran on a 96-core CPU machine with 96 parallel workers; systems are integrated independently, so the campaigns are embarrassingly parallel.
